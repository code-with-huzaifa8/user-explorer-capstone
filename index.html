JavaScript concepts used

Async/await and Event Loop

loadUsers() uses await to wait for the API response. While it waits, the browser can handle other work. After the Promise settles, the function continues.

Pagination

The app requests a batch of users from DummyJSON using limit and skip. This is offset-based pagination, not a true opaque cursor API.

Virtualisation

The list can contain many loaded users, but only rows around the visible scroll position are added to the DOM.

Closures

makeLoadHandler() returns a click handler that remembers the app state and loading function.

Hoisting

Function declarations such as loadUsers can be called before their written position. Variables declared with let and const cannot be used before initialization.

this and arrow functions

Arrow functions are used for callbacks and do not create their own this. This app avoids depending on this in event handlers.

Security and XSS

Comments, names, and emails are inserted with textContent, not innerHTML. This displays user input as text and helps prevent HTML injection and XSS.
