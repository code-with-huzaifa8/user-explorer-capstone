JavaScript Concepts Used

Variables and Data Types

The app uses const and let to declare variables. Strings, numbers, booleans, arrays, objects, and null are used to store and manage data.

Operators and Expressions

Arithmetic, comparison, logical, assignment, and spread operators are used to perform calculations, compare values, and update data.

Conditions and Control Flow

If statements, return statements, and the ternary operator control what happens in different situations.

Functions and Parameters

Functions organize reusable code. The app uses parameters, return values, default parameters, and object destructuring.

Scope and Closures

Scope controls where variables can be accessed. The function returned by makeLoadHandler remembers currentState and loadFunction from its outer scope.

Arrays and Objects

Users are stored in an array, and each user is represented by an object. The app uses map(), filter(), slice(), and the spread operator.

Template Literals and String Methods

Template literals create dynamic strings. The app uses toLowerCase(), includes(), trim(), and slice() to process text.

Loops

The for...of loop goes through the visible users and creates a row for each user.

DOM Manipulation

The app selects HTML elements, creates elements, changes text and styles, sets attributes, and adds or removes child elements using DOM methods.

Events and Event Object

Click, scroll, input, and submit events make the app interactive. The event object provides information about an event, and preventDefault() stops the form's default submission behavior.

Arrow Functions and Callbacks

Arrow functions are used as event callbacks. A callback is a function passed to another function to be executed later.

Async/Await and Promises

Async functions and await handle asynchronous API requests. fetch() and response.json() return Promises that can be awaited.

Fetch API and JSON

The Fetch API requests user data from DummyJSON. The response is checked, and response.json() converts the response body into JavaScript data.

Error Handling

Try, catch, finally, and throw handle request errors. The finally block resets the loading state even if a request fails.

Pagination

The app loads users in batches using limit and skip. This is offset-based pagination rather than true cursor-based pagination.

Virtualisation

The app renders only rows near the visible scroll position instead of adding every loaded user to the DOM.

DocumentFragment

DocumentFragment groups newly created rows before they are added to the page.

Event Loop

While an API request is pending, the browser can handle other work. After an awaited Promise settles, the async function resumes.

Hoisting

Function declarations can be called before their written position. Variables declared with let and const cannot be accessed before initialization.

The this Keyword

The app does not explicitly use this. Arrow functions do not create their own this value and instead inherit it from their surrounding scope.

Input Handling and Validation

The app reads search and comment input, trims comments, ignores empty comments, and uses HTML attributes such as required and maxlength.

XSS Security

The app uses textContent instead of innerHTML to display comments, names, and emails as text. This helps prevent HTML injection and cross-site scripting (XSS).

Strict Mode

The 'use strict' directive enables JavaScript strict mode, which helps catch certain coding mistakes.

Type Conversion

Number() converts the cursor position into a number, while String() converts the next position back into a string.

Accessibility and Semantic HTML

Labels, semantic elements, ARIA attributes, and keyboard focus support help make the app more accessible.

Built with HTML, CSS, and vanilla JavaScript
